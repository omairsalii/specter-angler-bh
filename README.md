# Specter Angler BH — الصَّيَّادُ الشَّبَح

تطبيق ويب عربي للصيد من الشاطئ بالطعم الصناعي في البحرين:
خريطة النقاط المرشّحة، مؤشر الصيد الساعي، «ماذا أربط؟»، دليل الأسماك، العُقد والدروس، وسجلّ الصيد.

- بيانات البحر: Open-Meteo
- الخرائط: OpenStreetMap / Esri
- صور الأسماك: Wikimedia Commons (المصوّر والرخصة مذكوران داخل التطبيق)
